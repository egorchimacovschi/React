# React

My dedication to React — a personal collection of practice projects and exercises, built on top of my JavaScript fundamentals, organized by folder.

## 📁 Repository Structure

| Folder | Content |
|---|---|
| [`Learning`](./Learning) | React fundamentals: component basics, JSX, and project structure/tooling. Currently contains [`initiation`](./Learning/initiation) — first steps with React using Vite (`Header`, `Footer`, `Food` components) |

More folders (standalone projects and exercises covering new React topics — state, hooks, props, routing, etc.) will be added here as new topics are covered.

Each folder has its own `README.md` with more detail on what's inside.

## ⚙️ Requirements

- [Node.js](https://nodejs.org/) (npm comes bundled with it)
- A modern web browser

## 🚀 Running

Each project folder is a standalone Vite + React app. To run one, e.g. `initiation`:

```bash
cd Learning/initiation
npm install
npm run dev
```

Then open the local URL Vite prints in your terminal (usually `http://localhost:5173`).

## 📌 Notes

- This repository is a personal learning log and grows as new React topics are covered.
- Projects are built with [Vite](https://vitejs.dev/) as the build tool.
